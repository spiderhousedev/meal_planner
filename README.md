# Meal Planner Project

```
npx expo start
```

## Problem 
I'm currently using iphone text messages to buy the correct shopping ingredients at the shops, sent to me by my partner. 

This gets tricky when we have other messages surrounding the list, or something gets added while I'm already shopping (ie, we forget something). 

## Proposal 
I'm planning to develop an application whereby we can:

- 'Perform CRUD operations' on what ingredients are needed for a set recipe

- Save & re-load each recipe, to prevent missing out some ingredients

- Plan our week according to what we want to eat and when, being able to view the recipes and ingredients along the way. 

- Save & place our recipes in sections that represent each day of the week. 

## Desires 
These are some of the initial desires we have about the final application.

- To be able to use both on our laptops and on our phones, preferably using webpages for laptops and a native ios application for our phones. 

- To be able to invite different members into our 'household' within the app, so that they can contribute to / read the weekly menu. 

- To be able to give our friends & family the app if they want to use it within their own homes. 

- Crucially, to make sure it's worthy of using rather than sticking to our current ways.
